Notation reference
  • Key Signature: 3/4 sets the time signature
  • Treble Clef1: / Bass Clef1: start a staff (Clef2, Clef3… add more pairs)
  • Line/space number: 0 middle line, positive = up, negative = down
  • Duration: w h q e s — add r for a rest, e.g. qr
  • Accidental prefix (this note only): sh- sharp, fl- flat
  • Finger: (1) … (5) after the note
  • Dot (notes): . right after the duration (e.g. q.) adds 50% to its length
  • Dot (rests): . right after the r (e.g. qr., hr.) adds 50% to its length
  • tie between two identical notes joins them — even across a page break into the next clef pair
  • { } groups notes played as a chord
  • Key signature rule: add <position>-sh or <position>-fl after the time signature, e.g. Key Signature: 4/4 0-sh 1-fl. This sharps/flats every note of that letter, on any line or space, on every staff — e.g. 0-sh makes every B sharp and 1-fl makes every C flat, the same way a real key signature works. To keep the sheet readable, notes affected only by this rule don't show a ♯/♭ mark on the staff (it's implied) — but the falling notes in the waterfall panel always spell it out clearly (e.g. "B♯", "C♭") along with the finger number, so it's never ambiguous during practice.
  • sh- / fl- directly on a note always overrides the key signature for that one note (and its ♯/♭ is shown on the staff, since it's an explicit accidental).
  • na- prefix (e.g. na-1q(3)) cancels the key signature's effect for just that one note, making it natural — shown on the staff as a ♮ mark.
  • Clef-only key signature: add -tr or -ba after a key signature rule to limit it to one clef — e.g. Key Signature: 4/4 1-sh 2-sh-tr -2-fl-ba makes every C sharp on both clefs, every D sharp on the Treble clef only, and every G flat on the Bass clef only. A clef-specific rule overrides a universal rule for that letter, but only on that one clef.
  • Repeats: define a group once — Repeat1: Clef1, Clef2, Clef3, Clef4 — then drop the token Repeat1 into any staff's note line to replay that whole group of pairs from there. Repeat the token itself to repeat the group multiple times, e.g. Repeat1 Repeat1 plays clef pairs 1–4, then plays clef pairs 1–4 again, before continuing on. The sheet still shows each clef pair's music only once — the repeat token itself appears as a small marker on the staff where you wrote it, and during playback the system jumps back to replay the referenced pairs the requested number of times.
